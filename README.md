# Belajar Dasar Pemrograman Web — Dicoding

Arsip latihan terstruktur selama menyelesaikan kelas **Belajar Dasar Pemrograman Web** di Dicoding. Repositori ini mendokumentasikan penerapan fondasi pengembangan web statis menggunakan HTML5 semantik dan CSS3 modern.

## Ringkasan Latihan & Pembelajaran

### 1. [`01-profil-kota-bandung`](./01-profil-kota-bandung)
Membangun halaman profil informasi Kota Bandung dari nol untuk menerapkan anatomi dokumen web yang terstandar:
- **HTML5 Semantik:** Mengorganisasi struktur konten menggunakan elemen `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, dan `<footer>` untuk meningkatkan keterbacaan kode serta aksesibilitas.
- **CSS Box Model & Styling:** Mengatur hierarki tipografi, palet warna, *padding*, *margin*, serta gaya visual kartu (*card*) dan gambar profil.
- **Layout Responsif:** Menerapkan *media queries* dan tata letak fleksibel agar tampilan menyesuaikan proporsi layar desktop maupun perangkat seluler.

### 2. [`02-landing-page-dicoding`](./02-landing-page-dicoding)
Mengembangkan halaman arahan (*landing page*) profil Dicoding dengan fokus pada penyusunan tata letak komponen antarmuka modern:
- **CSS Flexbox:** Menyusun bilah navigasi horizontal, *hero section* dua kolom (deskripsi teks dan visual utama), serta barisan tautan media sosial.
- **Pengelolaan Aset & Gaya:** Memisahkan struktur dokumen (`index.html`), lembar gaya (`css/app.css`), dan aset media (`img/`) secara modular.
